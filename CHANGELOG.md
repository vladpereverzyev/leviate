# Changelog

What changed in each version of Leviate. The web app, Leviate for Desktop and Leviate for
Chrome share one version number; Leviate for Blender has its own. The downloads of every
version are on the [releases page](https://github.com/vladpereverzyev/leviate/releases).

## Leviate (web app, Desktop, Chrome)

### 1.3.37 (2026-10-10)

- Leviate for Chrome: before **Use phone** the panel shows the same short Same Wi-Fi network
  note as the web app, with a link to how pairing works.
- Leviate for Chrome: on Chrome pages and the Chrome Web Store, where extensions cannot work,
  the panel says to open a website in the tab.

### 1.3.36 (2026-10-10)

- Leviate for Desktop runs on Electron 44.6.0, with its latest fixes.
- Shorter READMEs, with the guides in `docs/`.

### 1.3.35 (2026-10-10)

- The macOS app is signed with Developer ID and notarized by Apple: it opens with a double
  click, with no "Open Anyway".
- The release no longer carries the Microsoft Store package.

### 1.3.34 (2026-10-10)

- Leviate is on the [Snap Store](https://snapcraft.io/leviate) for Ubuntu and the other Linux
  systems with snap.
- Web app: messages show under the header, in the box of the Wi-Fi note, instead of a bar over
  the footer.
- Web app on phones: the windows start folded, with no closing animation, and **Try the demo**
  opens the webcam.
- Leviate for Desktop: package for the Microsoft Store.

### 1.3.33 (2026-10-10)

- Leviate for Linux also comes as a Flatpak and as a snap. Copies from a store or a package get
  their updates from there.

### 1.3.32 (2026-10-09)

- New: Leviate for Chrome and Leviate for Dentra Viewer.
- The phone camera shows a notice to keep the phone and the computer on the same Wi-Fi.
- The Ko-fi note opens in its own window in Leviate for Desktop.

### 1.3.31 (2026-10-07)

- The hand is found with medical gloves too: nitrile and latex in any color.

### 1.3.30 (2026-10-07)

- The header of the web app no longer shows the frame rate and the hand timing.
- The drawings of the poses show the double click.

### 1.3.29 (2026-10-07)

- Leviate for Desktop, Mouse module: keep the finger still after a left click and a second ring
  makes it a double click.

### 1.3.28 (2026-10-07)

- The oldest version still on the releases page: Leviate for Desktop with the 3D and Mouse
  modules for Windows, macOS and Linux.

## Leviate for Blender

### 1.3.12 (2026-10-09)

- Same Wi-Fi notice for the phone as in the other parts of Leviate.

### 1.3.11 (2026-10-08)

- The hand tracking runs in its own process and the hand model comes inside the add-on.

### 1.3.10 (2026-10-07)

- The hand is found with medical gloves too.

### 1.3.9 (2026-10-07)

- The first release of the add-on under its own version number.
